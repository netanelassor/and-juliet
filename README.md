# & Juliet · הבמה של רון

הספר האינטראקטיבי המלא: 48 סצנות, 48 איורים, 17 פרקים ושתי מערכות. כל 1,784 מילות הסיפור המקורי נשמרו, עם השם ג'ולייט ופונט Rubik.

**הגרסה המפורסמת:** https://netanelassor.github.io/and-juliet/

## איורי מקור ותחזוקה ממחשב אחר

כל 48 איורי ה־PNG המקוריים, ה־PDF המקורי, הכריכה העריכה, גיליון הדמויות, חמשת רקעי ההנפשה, הווילון וגיליונות התנוחות החדשים נשמרים עם הפרומפטים. שכפול רגיל של המאגר כולל את כולם. [תיקיית המקורות](source-assets/)

[הוראות תחזוקה](docs/ASSETS_MAINTENANCE.md) · [מפת ההנפשות](docs/ANIMATION_ASSETS.md) · [מלאי הקבצים והחתימות](source-assets/manifest.json) · [גרסאות דפוס, כפולות וארכיוני עיצוב](docs/ASSET_ARCHIVES.md)

להורדת חבילות המקור והגרסאות הקודמות: [Source assets and design archive](https://github.com/netanelassor/and-juliet/releases/tag/source-assets-v0.5.0). המקורות הכבדים אינם חלק מהורדת האתר לאייפד.

האיור והקריאה נמצאים במסגרת אחת עם כפתור ״ממשיכים״ במקום קבוע משמאל. מונה הסצנות פותח את הפרק הנוכחי עם תמונות לבחירה. נגן השירים נפתח מעל הסרגל ומצטמצם במעבר לסצנה הבאה. ב־38 הלהקה רוקדת, ב־46 ג׳ולייט מרימה את המיקרופון וב־48 הקאסט קד לקהל. אלה רצפים קצרים על בסיס תנוחות מאוירות משלימות. ביתר הסצנות הנפשות הבמה משתמשות באיורי המקור. ההנפשות חוזרות אוטומטית ואפשר להפעיל רגעים בנגיעה או לעצור את התנועה בהגדרות.

## לקריאה בלי רשת

בהגדרות בוחרים **הספר בא איתנו → נשמור את הספר לדרך**. גודל ההורדה מוצג בהגדרות. היא כוללת את כל 48 הסצנות ואת ההנפשות, עם עצירה והמשך. הדפדפן מנהל את האחסון ועשוי לפנות אותו כאשר חסר מקום. אם משתמשים באייקון במסך הבית, מבצעים את השמירה אחרי פתיחת הספר מהאייקון.

נגני Apple Music ו־Spotify המשולבים זקוקים לרשת. להאזנה בזמן קריאה בלי רשת, מורידים מראש את אלבום הקאסט באפליקציית ״מוזיקה״. בסצנה מופיעים שם השיר ומספר הרצועה. מפעילים את הרצועה מתוך ״ספרייה״, תחת ״הורדות״, וחוזרים לספר. [הורדת מוזיקה באייפון](https://support.apple.com/he-il/118288)

## עבודה מקומית

```sh
npm ci
npm run dev
```

פורט התצוגה הוא 4178. לבנייה עבור GitHub Pages:

```sh
VITE_BASE_PATH=/and-juliet/ npm run build
```

`dist/` כוללת גם את עובד השירות ומלאי השמירה שנוצרים בבנייה. אין הורדה מלאה לפני בחירה מפורשת. תהליך הפרסום ידני ומעלה את `dist/` בלבד.

לפי בקשת המשתמש לא נוספו ולא הורצו בדיקות אוטומטיות, ותהליך GitHub Actions מריץ התקנה ובנייה. בדיקות השימור הקודמות נשמרו למקרה שיידרשו בעתיד. ההפקה כוללת בנייה וצפייה חזותית במסכים מייצגים, ללא אישור על אייפד פיזי או חשבון מוזיקה משפחתי.
