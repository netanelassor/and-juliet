# Optional offline reading

Settings mounts `<OfflineBook/>`. The App also observes the browser's online status so it can switch the music interface to the offline listening instructions. The Vite config imports the offline build plugin and uses port 4178 for dev and preview.

The production build inventories its actual output and emits `offline-book-manifest.json` and `offline-book-sw.js`. The inventory contains the built HTML/JS/CSS, all 48 original story illustrations, all 48 thumbnails, every clean plate present in `assets/premium`, cover/character/theatre artwork, local fonts, and icons. The plugin rejects a build missing any of the 48 original illustrations or thumbnails. Its version derives from file contents and the worker implementation. No audio/video extension or remote URL can enter the inventory.

The build requires all 28 choreography keyframes for scenes 15, 17, 18, 20, 26, 31, 33, 36, 38, 40, 42, 43, 46 and 48, and the corrected stills under `assets/performance`. A complete saved edition includes them. Readers with an older saved edition can refresh it from Settings while connected.

Opening Settings requests only the small inventory and the status of an already installed worker. The explicit “נשמור את הספר לדרך” action registers the worker and starts the book download. Size, progress, cancellation, storage errors, and retry are visible. The worker verifies the size and SHA-256 of each response before caching it. Cancellation preserves verified files and a previous complete edition. Completion is reported after every inventory file is cached and the completion marker is written.

The worker is scoped to the application base, including `/and-juliet/` on GitHub Pages. It requests fresh navigation and book assets online, then falls back to saved resources if the network fails. It never forces a page reload for an update. An incomplete new download does not replace the previous complete offline edition; after success it retains the current and one previous complete edition. Cache cleanup is limited to this book's exact scope-specific prefix and never deletes another application's caches.

Download requests omit credentials. Cache keys are plain local URLs, without request cookies or authorization headers. External origins, including Apple Music, Spotify, sign-in, and provider player data, pass through without caching. The official web players require internet. The offline scene cue shows an official link plus the exact cast-album track number. Listeners who have downloaded the album can play the track in the Music app under Library → Downloaded and return to the book. The website cannot inspect or start those protected downloads. Music link handoff and background playback need verification on a physical iPhone.

The reader should leave the book open until saving finishes. iPadOS may stop an unfinished download after the app is closed or suspended. Service workers require HTTPS or localhost; an insecure LAN address and Vite's development module server do not offer offline saving. Browser storage restrictions, private browsing, capacity limits, and later browser eviction can prevent or remove the saved copy. The UI does not promise permanent storage, background completion, offline music, or a human narration recording.

On iPhone or iPad, when using a Home Screen icon, open the book through that icon before downloading it. The Home Screen app and Safari may use separate storage.
