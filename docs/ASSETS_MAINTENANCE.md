# תחזוקת המקורות של הספר

מקורות העבודה נשמרים ישירות ב־[source-assets/](../source-assets/README.md), לצד הקוד ונכסי ההפעלה במאגר. [מלאי המקורות](../source-assets/manifest.json) כולל נתיבים ניידים, גדלים וחתימות SHA-256. [ארכיוני הגרסאות](ASSET_ARCHIVES.md) כוללים את מהדורות הדפוס, הכפולות, האבטיפוסים והיסטוריית ההפקה.

## מה עורכים

| תחום | מקור העבודה במאגר |
|---|---|
| סדר הקריאה, 17 הפרקים וכל 48 הסצנות | `src/content/chapters-data.json` |
| נוסח הסיפור המלא לפי מספר סצנה | `src/content/full-story.json` |
| הקשר ל־PDF המקורי וטביעות האצבע של האיורים | `src/content/source-inventory.json` |
| איורי הדפדפן | `public/assets/story/scene-01.webp` עד `scene-48.webp` |
| כריכה ולוגו בדפדפן | `public/assets/cover/` |
| איורי השלמה להנפשה | `public/assets/premium/` והפרומפטים ב־`docs/PREMIUM_ASSET_PROVENANCE.json` |
| הווילון | `public/assets/theatre/curtain-illustrated-v1.webp`, `TheatreCurtain.tsx` והסגנון שלו |
| עימוד, צבעים ו־Rubik בגודל 24 | `src/styles/premium-design.css`; הפונט ב־`public/assets/fonts/` |
| מסכות הדמויות והנפשות בחמש סצנות המפתח | `src/components/PremiumStage.tsx` והסגנון שלו |
| הנפשות שאר הסצנות | `Stage.tsx`, `TheatricalEffects.tsx`, `src/motion/scene-motion.ts` |

הנוסח האינטראקטיבי מכיל את 1,784 מילות המקור, עם החלפת השם ליוליה → ג'ולייט כפי שהתבקשה. כשעורכים טקסט, מעדכנים את סצנת המקור וגם את העותק שלה בפרק המתאים. אין להחליף את הנוסח בטקסט של מהדורת הדפוס v9: זו מהדורה נפרדת בת 1,847 מילים.

אותם 48 מקורות PNG נמצאים גם בחבילת המקור וגם בנכסי v9, וזהים בית לבית לטביעות האצבע שבמלאי הסיפור. די לשמור עותק מקורי אחד. קובצי WebP והתמונות המוקטנות הם נכסי ההפעלה; אין להשתמש בהם במקום מקורות PNG לעריכת האיור.

רקעי ההשלמה מסתירים את החלל שמאחורי הדמויות בזמן תנועה. הדמויות הנראות מגיעות מהאיורים המקוריים דרך מסכות בקוד. לכן חייבים לשמור יחד את האיור, רקע ההשלמה וקוד המסכה. כתובת מקומית מתחת ל־`.codex/generated_images` אינה גיבוי: יש להעתיק את ה־PNG עצמו לארכיון המקורות ולרשום במלאי את נתיבו הנייד.

## מקורות סיפור, עיצוב והיסטוריה

שומרים את `and-juliet-book-he.pdf` המקורי בן 60 העמודים, SHA-256:

`9f79819126904d02408e7b1af58c1faa13f793654ba2c8e3ffdd59a9b0e1460b`

לצדו שומרים את כתב היד המקורי, שבעת קובצי הפרומפטים, מטא־נתוני ההפקה ושלושת מסמכי ההנחיות: `and_juliet_production_bible_he.md`, `CODEX_AND_JULIET_EDITORIAL_REDESIGN.md`, `AND_JULIET_INTERACTIVE_IPAD_CODEX_BRIEF.md`. הם מתעדים את ההיסטוריה; השינויים המאושרים המאוחרים והקוד הנוכחי מגדירים את המוצר הקיים.

הארכיון של v9 צריך לכלול את תיקיות `editable/`, `assets/` ו־`docs/` יחד. קובצי ה־SVG של הכפולות מפנים יחסית לאיורים בתיקיית `assets/`; הכותרת הקדמית העצמאית נשמרת בנפרד. קובצי JPG מלאים, PDF מודפס, תצוגות מקדימות, סרטוני הדגמה וחבילות של גרסאות קודמות מתאימים לארכיוני Release היסטוריים. קוד המקור הנוכחי, נכסי ההפעלה ומסמכי התחזוקה נשארים ב־Git. `node_modules/` ו־`dist/` ניתנים ליצירה מחדש ואינם מקורות גרפיים.

## עבודה ממחשב אחר

משכפלים את המאגר, מתקינים Node.js 24 ומריצים:

```sh
npm ci
npm run dev
```

לבניית האתר בפרויקט `and-juliet`:

```sh
VITE_BASE_PATH=/and-juliet/ npm run build
```

הפצה מתבצעת דרך תהליך ה־Deploy הידני ב־GitHub. לפי בקשת המשתמש אין להוסיף או להריץ בדיקות אוטומטיות כחלק מהעבודה השוטפת; מבצעים בנייה וצפייה חזותית בסצנות שהשתנו, לרבות סצנה צפופה ו־iPad רוחבי. קובצי האודיו אינם חלק מהמאגר: הנגנים משתמשים בשירותי Apple Music ו־Spotify, והקראת המכשיר תלויה בקול הזמין בו.

## שחזור מקורות והיסטוריה

כל המקורות החשובים לגרסה הנוכחית כלולים ב־Git עצמו. אין צורך בתיקייה מקומית, בחשבון Git LFS או ב־Codex כדי להריץ ולשפר את האתר. ההיסטוריה הגדולה נשמרת ב־[Release המקורות](https://github.com/netanelassor/and-juliet/releases/tag/source-assets-v0.5.0), עם מדריך לכל ארכיון וחתימות להורדה ב־[ASSET_ARCHIVES.md](ASSET_ARCHIVES.md). קובצי המקור אינם מתווספים ל־public ולכן אינם מכבידים על קריאת הספר באייפד.

לבדיקת שלמות הגיבוי אפשר לחשב SHA-256 ולהשוות ל־manifest. זו בדיקת קבצים בלבד, ללא צורך בהרצת בדיקות יישום. מתכוני המסכות והקשר בין המקורות להנפשה מתועדים ב־[ANIMATION_ASSETS.md](ANIMATION_ASSETS.md).
